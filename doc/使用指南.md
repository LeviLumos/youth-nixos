# 使用指南 —— 装好系统之后的日常操作

> 面向**日常使用**。安装步骤、变量表、模块说明、构建排错见 [`系统需求.md`](系统需求.md)；
> 键位详解与改键教程见 [`whichkey.md`](whichkey.md)；zsh/kitty/VSCodium 见各自文档。
>
> 最常用的一键速览：`super+space` 启动器、`super+t` 终端、`super+o` 总览、
> `super+q` 关窗口、`super+alt+l` 锁屏、`Print` 截图、`ctrl+space` 中文输入。

---

## 1. Wi-Fi 连接（NetworkManager）

没有托盘图标（状态栏已移除），用下面两种方式之一，连一次之后**开机自动重连**。

```bash
nmtui                                        # ① 终端里的图形向导（推荐）
```

进去选 `Activate a connection` → 选网络 → 输密码 → `<Back>` 返回。断开/开关 Wi-Fi 也在里面。

命令行（快，适合脚本）：

```bash
nmcli device wifi list                       # 扫描周围的网络（SSID / 信号 / 加密）
nmcli device wifi connect "SSID" password "密码"   # 连接
nmcli connection show                        # 已保存的连接
nmcli connection down <连接名>; nmcli connection up <连接名>
nmcli connection delete <连接名>              # 忘记这个网络
nmcli radio wifi off                         # 关 Wi-Fi（on 打开）
```

排错：`journalctl -u NetworkManager -e`、`nmcli general status`。

## 2. 蓝牙

**图形**：`super+space` 启动器里搜 **Bluetooth Manager**（Blueman）——
搜索 / 配对 / 信任 / 连接都是点点点。

**命令行**（`bluetoothctl`，交互式）：

```
$ bluetoothctl
[bluetooth]# power on
[bluetooth]# scan on
#    等目标设备出现，记下 MAC 地址（XX:XX:XX:XX:XX:XX）
[bluetooth]# pair XX:XX:XX:XX:XX:XX
[bluetooth]# trust XX:XX:XX:XX:XX:XX     # trust 后开机自动重连
[bluetooth]# connect XX:XX:XX:XX:XX:XX
```

蓝牙耳机连上后，在 `pavucontrol` 的「配置」页选 **A2DP Sink**（高音质，默认是打电话的 HFP）。

排错：`systemctl status bluetooth`；`rfkill list` 看是否被屏蔽（`rfkill unblock bluetooth`）。

## 3. 音量调节

| 方式 | 操作 |
| --- | --- |
| 键盘多媒体键 | 音量 `+` / `−` 每次 ±5%（长按连调）、静音键 |
| 图形 | 启动器搜 **PulseAudio Volume Control**（pavucontrol） |
| 命令行 | 见下 |

```bash
wpctl set-volume @DEFAULT_AUDIO_SINK@ 10%+   # 大 10%
wpctl set-volume @DEFAULT_AUDIO_SINK@ 10%-   # 小 10%
wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle   # 静音切换
wpctl status                                 # 列出所有输入/输出设备和默认设备
pactl set-source-mute @DEFAULT_SOURCE@ toggle # 麦克风静音
```

pavucontrol 五个页签：**回放**（每个应用单独音量）/ **录音** / **输出设备**（选默认）/
**输入设备** / **配置**（蓝牙耳机选 profile）。

音频服务是 **PipeWire**（兼容 PulseAudio / JACK / ALSA）。没声音先看：
`systemctl --user status pipewire wireplumber`，再看默认输出对不对（`wpctl status`）。

## 4. 屏幕亮度

| 方式 | 操作 |
| --- | --- |
| 键盘亮度键 | 每次 ±5%（长按连调） |
| 命令行 | 见下 |


## 6. 电源 / 电池

| 键位 | 动作 |
| --- | --- |
| `super + alt + l` | 锁屏（swaylock，壁纸同款背景） |
| `super + alt + s` | 挂起 |
| `super + alt + h` | 休眠（需 swap ≥ 内存，见 系统需求.md） |
| `super + alt + w` | 先挂起，2 小时后自动转休眠 |

性能档位（`powerprofilesctl`）：

```bash
powerprofilesctl get                          # 当前档位
powerprofilesctl set performance              # 性能 / balanced / power-saver
```

电池：`btop` 里看，或 `upower -d | grep -E 'state|percentage'`。

默认行为（改 `vars.nix`）：用电池时**合盖=挂起**、插电时**合盖=不动作**；
空闲 5 分钟自动锁屏、10 分钟关屏（`vars.desktop.lockAfter / screenOffAfter`）。

## 7. 外接显示器 / 投影

niri 插上线**自动点亮**。查看与手动调整：

```bash
niri msg outputs                             # 列出所有输出与分辨率
niri msg output DP-1 mode 1920x1080          # 设分辨率
niri msg output DP-1 position 1920+0         # 摆到主屏右侧
niri msg output DP-1 scale 1.5               # 缩放（高分屏用）
niri msg output DP-1 off                     # 关掉
```

想要「一插上就自动套预设」（会议室投影、家里扩展坞），需要 **kanshi**——目前没装，
需要就说一声，10 行配置就能加。

## 8. 中文输入（fcitx5 + Rime）

- 切换：`ctrl + space`（装好就能用，不用手动添加输入法）
- 默认方案：**雾凇双拼**；词库首次用 `just rime-ice` 装，装完 `just ime-restart`
- 管理输入法列表 / 换方案：启动器搜 **Fcitx 配置**（`fcitx5-configtool`）
- 方案与候选个数定制：`~/.local/share/fcitx5/rime/default.custom.yaml`
  （nix 部署的软链，改仓库里的 `dotfiles/rime/default.custom.yaml`）
- 打不出中文：先 `just ime-restart`，再看 `~/.config/fcitx5/profile` 里有没有 `Name=rime`

## 9. 打印 / 扫描

## 10. 系统更新 / 回滚

```bash
cd /etc/nixos
git pull origin ego         # 拉最新配置
just switch                # 应用（写入引导，随时可回滚）

just update && just switch  # 升级 nixpkgs 等依赖（update 完必须 switch 才生效）

sudo nixos-rebuild switch --rollback   # 回到上一世代（当下就切回去）
```

开机选择世代：重启时停在 **systemd-boot 菜单**，选上一条 `NixOS - Configuration`。

> ⚠️ 家目录的配置（`~/.zshrc` 等）是 `/nix/store` 的**只读软链**，直接改无效。
> 要改仓库里的 `dotfiles/` 再 `just switch`；本机私有的东西写 `~/.zshrc.local`（见 zsh.md）。

## 11. 磁盘空间

```bash
just store-size            # 看余量与 /nix/store 占用
just free-disk             # 清旧世代 + store 去重（磁盘告急先跑它）
just gc-status             # 看自动回收时间（每周自动，保留 7 天）
```

构建大件之前盘上留 **10G+** 余量。

## 13. 故障排查速查

| 症状 | 处理 |
| --- | --- |
| `just switch` 被杀（`SIGKILL: 9` / 247） | 内存不足：先 `just swap-on` 再 `just switch-safe` |
| `No space left on device` | 先撤 swapfile（`sudo swapoff /swapfile && sudo rm -f /swapfile`）再 `just free-disk` |
| 拉仓库超时 / GitHub 不通 | 网络问题，配代理：`sudo --preserve-env=http_proxy,https_proxy nixos-rebuild switch --flake .` |
| 没声音 | `wpctl status` 看默认输出；`systemctl --user status pipewire wireplumber` |
| 键位没反应 | `super+shift+/` 看浮层里有没有；`super+escape` 解除应用拦截；详见 whichkey.md 第 7 节 |
| Wi-Fi 连不上 | `nmtui` 重试；`journalctl -u NetworkManager -e` |
| niri 启动失败 / 黑屏退 TTY | KDL 写错：`journalctl -b -u niri`；改 `dotfiles/niri/config.kdl` 后重新 switch |
| 想看本次开机所有报错 | `journalctl -b -p err` |
| 配置改了没生效 | nix 管的必须 `just switch`（niri 的 config.kdl 除外——它热重载） |

## 14. `just` 命令一览

在 `/etc/nixos` 里跑（`just` 不带参数 = 列出全部）：

| 命令 | 作用 |
| --- | --- |
| `just switch` | 正式切换（写入引导） |
| `just test` | 试运行（重启就回退） |
| `just switch-safe` | 低内存构建（`--max-jobs 1 --cores 2`） |
| `just build` | 只构建不切换 |
| `just update` | 更新 flake 依赖（完了要 `just switch`） |
| `just mem` | 看内存 / swap |
| `just swap-on` / `swap-off` | 临时开 / 关 8G zram swap |
| `just store-size` | 看磁盘余量与 /nix/store 占用 |
| `just free-disk` | 清旧世代 + 去重 |
| `just gc` / `gc-all` / `gc-old` / `gc-status` | 手动回收 / 激进回收 / 温和回收 / 看定时器 |
| `just hw` | 重新生成本机硬件配置 |
| `just rime-ice` | 装/更新雾凇拼音词库 |
| `just ime-restart` | 重启输入法 fcitx5（改了方案/词库后） |
| `just code-ext` | 按 `~/.config/VSCodium/extensions.txt` 装插件 |
| `just font-check` | 校验 Maple Mono 字体族名 |
| `just niri-actions` | 列出 niri 支持的所有 action |
