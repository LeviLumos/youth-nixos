## 三、设计约定

| 约定 | 说明 |
| --- | --- |
| 单一变量源 | 所有可变项集中在 `vars.nix`，其它文件一律从中取值，改一处全局生效 |
| 最小粒度 | 一个功能一个模块文件；home 侧按应用拆：`niri / kitty / zsh / packages / desktop` |
| dotfile 用 `home.file` | 不用 `programs.*` 生成配置；`dotfiles/` 下是真实可读的原生配置文件 |
| 占位符替换 | dotfile 里的 `@xxx@` 由 `pkgs.replaceVars` 在构建期替换成 `vars.nix` 的值 |
| 机器信息不入库 | `hardware-configuration.nix` 不进仓库，由 `hosts/<hostname>/default.nix` 自动探测 |

### 占位符机制（重要）

```
vars.nix  →  modules/home/*.nix（提供键值）  →  dotfiles/*（@占位符@）  →  ~/.config/...
```

```nix
# modules/home/niri.nix
home.file.".config/niri/config.kdl".source =
  pkgs.replaceVars ../../dotfiles/niri/config.kdl {
    gaps = toString vars.niri.gaps;
    # ...
  };
```

⚠️ `replaceVars` 会**故意构建失败**来防止疏漏，两种报错：

- dotfile 里有 `@xxx@`，但模块里没提供 `xxx` → 报错
- 模块里提供了 `xxx`，但 dotfile 里没有 `@xxx@` → 报错

即：**加/删占位符时，两侧必须同步**。

## 八、安装与使用

### 1. 全新安装

```bash
# 1) 官方 ISO 启动，进入 live 环境
sudo -i

# 2) 分区挂载（示例：UEFI + ext4）
mkfs.vfat -F32 /dev/nvme0n1p1
mkfs.ext4 /dev/nvme0n1p2
mount /dev/nvme0n1p2 /mnt
mkdir -p /mnt/boot && mount /dev/nvme0n1p1 /mnt/boot

# 3) 克隆本仓库（放到 /mnt/etc/ 下，安装后就是 /etc/youth-nixos）
git clone https://github.com/<you>/youth-nixos.git /mnt/etc/youth-nixos
cd /mnt/etc/youth-nixos

# 4) ★ 生成硬件配置并放入 hosts/<hostname>/（必须，否则构建会明确报错）
nixos-generate-config --root /mnt
cp /mnt/etc/nixos/hardware-configuration.nix ./hosts/ego/
# 该文件必须被 git 跟踪（flake 只拷贝 git 已跟踪的文件）：
git add -f hosts/ego/hardware-configuration.nix

# 5) 安装（#ego 来自 vars.hostname）
nixos-install --flake .#ego --no-root-passwd
reboot
```

### 2. 已装好 NixOS，切到这套配置

```bash
git clone https://github.com/<you>/youth-nixos.git ~/youth-nixos
cd ~/youth-nixos

# ★ 生成本机硬件配置放到 hosts/<hostname>/ 下
sudo nixos-generate-config --show-hardware-config > hosts/ego/hardware-configuration.nix

sudo nixos-rebuild test --flake .#ego      # 试运行（重启可回退）
sudo nixos-rebuild switch --flake .#ego    # 正式切换
```

### 3. 日常命令（just = 写 CLI 命令的工具）

```bash
just switch   # sudo nixos-rebuild switch --flake .
just test     # 试运行
just build    # 只构建
just update   # nix flake update
just gc       # 清理 30 天前的旧世代
```

没有 just 时直接用：

```bash
sudo nixos-rebuild switch --flake .#ego
nix flake update
```

> 因为 `nixosConfigurations` 的名字就是 `vars.hostname`，
> 在目标机器上 `sudo nixos-rebuild switch --flake .` 可以省略 `#ego`。

### 4. 启动 niri

- `vars.nix` 中 `niri.autoLogin = false`（默认）：TTY 登录后执行 `niri-session`
- 改成 `true`：开机由 greetd 直接进入 niri（免密）

## 九、桌面组件与输入法

### 状态栏 / 壁纸 / 锁屏 / 通知 / 托盘 / 空闲

| 功能 | 软件 | 配置位置 | 触发方式 |
| --- | --- | --- | --- |
| 状态栏 | waybar | `dotfiles/waybar/{config.jsonc,style.css}` | niri `spawn-at-startup`（开机自启） |
| 壁纸 | swaybg | `vars.desktop.wallpaper` | niri `spawn-sh-at-startup` |
| 锁屏 | swaylock | PAM 在 `modules/nixos/desktop.nix` | `super + alt + l` |
| 通知 | mako | `modules/home/desktop.nix`（`services.mako`） | home-manager systemd 用户服务 |
| 托盘 | tray-tui | `dotfiles/tray-tui/config.toml` | `super + shift + t`（在 kitty 里打开） |
| 空闲行为 | swayidle | `modules/home/desktop.nix`（`services.swayidle`） | 空闲计时自动触发 |
| 音量混音器 | pavucontrol | `modules/home/packages.nix` | waybar 音量模块左键点击 |

- **壁纸**：默认读 `~/Pictures/wallpaper.jpg`。把图片放过去或改 `vars.desktop.wallpaper`；
  文件不存在时 swaybg 会退出，不影响其它功能。
- **waybar 的 niri 模块**：配置里用了 `niri/workspaces`、`niri/window`。
  若 `waybar` 日志出现 `unknown module`，说明该 waybar 构建没带 niri 支持，
  把 `dotfiles/waybar/config.jsonc` 里这两项删掉即可。
- **mako 没起来**：把 `dotfiles/niri/config.kdl` 里 `spawn-at-startup "mako"` 那行取消注释
  （注意与 home-manager 的 mako 服务二选一，避免双开）。

### 水杉输入法（MSIME）

- 来源：`github:metasequoiaime/msime` 的 `overlays.default` → `pkgs.msime-fcitx5`
- 框架：fcitx5（官方 NixOS 方案目前**只接了 fcitx5**，没有设置窗口和语音输入）
- 环境变量 `GTK_IM_MODULE` / `QT_IM_MODULE` / `XMODIFIERS` 由 `i18n.inputMethod` 自动设置，
  **不要**在别处重复定义（会冲突报错）
- fcitx5 通过 XDG autostart 启动，`niri-session` 支持该机制，无需手动拉起

**首次使用必做**（每个用户跑一次，下载约 189MB 词库）：

```bash
msime-linux-setup --download
```

之后：

- 未自动加入输入法时：`fcitx5-configtool` → 添加「水杉输入法」
- 升级后：`fcitx5 -r` 或重新登录
- 切换输入法默认快捷键：`Ctrl+Space`（fcitx5 默认），可在 `fcitx5-configtool` 里改

**关闭输入法**：`vars.nix` 里 `inputMethod.enable = false`。

### 空闲行为（swayidle）

`vars.nix` 里两个值，改完 `just switch` 即生效：

```nix
desktop.lockAfter      = 300;   # 空闲 5 分钟 → swaylock 自动锁屏
desktop.screenOffAfter = 600;   # 空闲 10 分钟 → 关闭显示器
power.suspendAfter     = 0;     # 改成 1800 → 空闲 30 分钟自动挂起
power.hibernateAfter   = 0;     # 改成 3600 → 空闲 1 小时自动休眠（需 swap）
```

- 全部设为 `0` 即完全关闭 swayidle（模块自动 `enable = false`）
- 睡眠前一定先锁屏：`events = [{ event = "before-sleep"; command = "swaylock -f"; }]`
- 查状态：`systemctl --user status swayidle`
- 关屏用的是 `niri msg action power-off-monitors`；如果你的 niri 版本没有这个 action，
  把 `modules/home/desktop.nix` 里的命令换成 `wlopm --off '*'`（并把 `pkgs.wlopm` 加进包列表）

### 音频（PipeWire）

```nix
hardware.audio = true;          # false 即关闭（关掉就没有声音）
```

- 混音器：`pavucontrol`（启动器里搜 PulseAudio Volume Control），或 waybar 音量模块左键点击
- 命令行：`pactl set-sink-volume @DEFAULT_SINK@ +5%`、`wpctl status`
- 组件：pipewire + wireplumber + ALSA/PulseAudio/JACK 兼容层（都在 `modules/nixos/desktop.nix`）

### 蓝牙

```nix
hardware.bluetooth = true;      # false 即整体关闭
```

- 图形管理：启动器里搜 **Bluetooth Manager**（blueman）
- 命令行：`bluetoothctl`（`power on` → `scan on` → `pair <MAC>` → `connect <MAC>`）
- 状态栏上有 `BT on/off`，点击打开 blueman

### 打印 / 扫描

```nix
hardware.printing = true;       # CUPS + Avahi
hardware.scanning = true;       # SANE
```

- 管理界面：<http://localhost:631>（CUPS）
- 现代网络打印机走 IPP Everywhere / driverless，默认**不需要驱动**
- 老机型才需要驱动，按需在 `modules/nixos/printing.nix` 里打开：
  `drivers = [ pkgs.gutenprint ];`（惠普一体机用 `pkgs.hplip`）
- 扫描后端同理在 `hardware.sane.extraBackends` 里加（网络扫描仪推荐 `pkgs.sane-airscan`）
- 命令行打印：`lpstat -p`（列出）、`lp -d <打印机名> <文件>`

### 电源管理 / 挂起 / 休眠

```nix
power.enable            = true;
power.cpuFreqGovernor   = null;      # 或 "powersave" / "performance"
power.lidSwitch         = "suspend"; # 合盖挂起
power.powerKey          = "suspend"; # 电源键挂起
```

- 电源档位切换：`powerprofilesctl set performance | balanced | power-saver`
  （状态栏 `PWR` 模块：左键=performance，中键=balanced，右键=power-saver）
- 手动挂起/休眠的键位：`super+alt+s` / `super+alt+h` / `super+alt+w`（先挂起再休眠）
- **休眠（hibernate）真正可用还需要机器侧配置**：
  1. swap 分区/文件大小 ≥ 物理内存
  2. 在 `hosts/<hostname>/hardware-configuration.nix` 里加：
     `boot.resumeDevice = "/dev/disk/by-uuid/<swap 的 UUID>";`
  3. 验证：`systemctl hibernate`；失败看 `journalctl -u systemd-hibernate`
  4. 不想折腾就用 `suspend`（挂起到内存）或 `suspend-then-hibernate`

## 十、二次加工：改成你自己的配置

### 场景 A：只改用户名和主机名（最常见）

1. 改 `vars.nix`：

   ```nix
   username = "alice";
   hostname = "thinkpad";
   ```

2. 因为 `hosts/` 目录名与主机名绑定：

   ```bash
   git mv hosts/ego hosts/thinkpad
   ```

3. 完毕。以下位置**全部自动跟着变**：用户与家目录、`home-manager.users.<name>`、
   `networking.hostName`、flake 输出名、`.zshrc` 的 rebuild 别名与 HISTFILE、greetd 登录用户。

### 场景 B：换显卡

```nix
graphics.gpu = "nvidia";   # amd / intel / nvidia / none
```

NVIDIA 还会启用 `services.xserver.videoDrivers = [ "nvidia" ]` 与 `hardware.nvidia.*`
（默认不锁版本，需要锁定 stable 就打开 `modules/nixos/graphics.nix` 里那行注释）。

### 场景 C：改主题 / 字体 / 桌面组件

只改 `vars.nix`：

- `theme.*` → niri 边框、kitty、waybar、mako、tray-tui 同步变化
- `fonts.mono.*` → 字体包/变体/族名/字号（族名用 `fc-list | grep -i maple` 核对）
- `desktop.*` → 状态栏/壁纸/锁屏/托盘的**程序与路径**

### 场景 D：改 niri 样式 / 键位

直接编辑 `dotfiles/niri/config.kdl`；需要"随变量变化"的值做成 `@占位符@`，
并在 `modules/home/niri.nix` 里补同名键（两侧必须同步，否则构建失败）。

### 场景 E：增删软件包

- 系统级：`modules/nixos/packages.nix`
- 用户级：`modules/home/packages.nix`

### 场景 F：加新 dotfile

```nix
# modules/home/git.nix
{ pkgs, ... }: {
  home.file.".gitconfig".source = pkgs.replaceVars ../../dotfiles/git/.gitconfig {
    userName  = "youth";
    userEmail = "youth@example.com";
  };
}
```
再在 `modules/home/default.nix` 的 `imports` 里加 `./git.nix`。

## 十一、注意项 / 风险清单

### 1. 必须你亲自做的

| 项 | 说明 |
| --- | --- |
| `hosts/<hostname>/hardware-configuration.nix` | **仓库不再内置**。`sudo nixos-generate-config --show-hardware-config > hosts/ego/hardware-configuration.nix`；缺失时构建会给出明确报错；该文件需被 git 跟踪（flake 只拷贝已跟踪文件） |
| `vars.fonts.mono.family` | 默认 `MapleMonoNormal NF CN`，用 `fc-list \| grep -i maple` 核对 |
| `vars.desktop.wallpaper` | 默认 `~/Pictures/wallpaper.jpg`，换成你自己的图 |
| `vars.initialPassword` | 默认 `youth`，装完请 `passwd` 修改 |
| 水杉输入法首次配置 | 必须跑一次 `msime-linux-setup --download` |
| fcitx5 环境变量 | 已由 `i18n.inputMethod` 设置，别处不要重复定义 |
| 休眠（hibernate） | 默认只做了系统侧；要真正能休眠还需 swap ≥ 内存并在硬件配置里写 `boot.resumeDevice` |

### 2. 包属性自检（首次构建前建议跑一遍）

```bash
nix eval nixpkgs#python314.name
nix eval nixpkgs#nodejs_24.version
nix eval nixpkgs#maple-mono.Normal-NF-CN.name
nix eval nixpkgs#tray-tui.version
nix eval nixpkgs#waybar.name  nix eval nixpkgs#swaybg.name  nix eval nixpkgs#swaylock.name
nix eval nixpkgs#mako.name    nix eval nixpkgs#vscodium.name
nix eval nixpkgs#swayidle.name  nix eval nixpkgs#pavucontrol.name  nix eval nixpkgs#blueman.name
nix eval nixpkgs#google-chrome.name  nix eval nixpkgs#obsidian.name
nix eval nixpkgs#uv.name  nix eval nixpkgs#yazi.name  nix eval nixpkgs#lazygit.name
nix eval nixpkgs#zen-browser.name     # 预期报错 → 所以用了社区 flake（方案 A）
```

查不到就 `nix search nixpkgs#<关键字>` 找新名字，再改 `vars.nix` 或对应模块。

| 位置 | 值 | 说明 |

| `flake.nix` → `nixpkgs.url` | `nixos-26.05` | nixpkgs 通道 |

## 十二、键位速查与配置调整

完整的键位表与改法见 [`doc/whichkey.md`](whichkey.md)，这里只记要点。

### 1. 键位只有一处

```
dotfiles/niri/config.kdl   ← 唯一来源（binds { ... }）
modules/home/niri.nix      ← 部署 + 替换 @占位符@
vars.nix                   ← 换「程序」（启动器/终端/锁屏/托盘）
```

- 换**程序** → 改 `vars.nix`（`niri.launcher` / `niri.terminal` / `desktop.locker` / `desktop.tray`）
- 换**键位或动作** → 改 `dotfiles/niri/config.kdl`

### 2. 需求里的七条键位（速查）

| 需求 | 键位 | action |
| --- | --- | --- |
| (1) 应用启动器 | `super + space` | `spawn "fuzzel"` |
| (2) 左/下/上/右 | `super + h/j/k/l` | `focus-column-left` / `focus-window-down` / `focus-window-up` / `focus-column-right` |
| (3) 终端 | `super + t` | `spawn "kitty"` |
| (4) 关闭窗口 | `super + q` | `close-window` |
| (5) 工作区上/下 | `super + u/i` | `focus-workspace-up` / `focus-workspace-down` |
| (6) 窗口移到左/右 | `super + [` / `super + ]` | `move-column-left` / `move-column-right` |
| (7) 上/下一个 | `super + 9/0` | `move-window-up` / `move-window-down`（列内移动一位） |

### 3. 桌面 / 电源键位

| 键位 | 动作 |
| --- | --- |
| `super + alt + l` | 锁屏 |
| `super + alt + s` | 挂起 |
| `super + alt + h` | 休眠 |
| `super + alt + w` | 先挂起，2h 后转休眠 |
| `super + shift + t` | 系统托盘 tray-tui |
| `super + shift + /` | 显示快捷键浮层（which key） |
| `super + shift + e` | 退出 niri（保底，别删） |

### 4. 改键位的流程

1. 编辑 `dotfiles/niri/config.kdl` 的 `binds { }`
2. 如果写了新的 `@占位符@`，必须在 `modules/home/niri.nix` 里补同名键（否则构建失败）
3. 桌面里 niri 会**热重载**；改了 nix 文件才需要 `just switch`
4. 按 `super + shift + /` 验证浮层里有没有新键位

### 5. 配置文件的实时位置

| 配置 | 部署后的位置 |
| --- | --- |
| niri | `~/.config/niri/config.kdl` |
| kitty | `~/.config/kitty/kitty.conf` |
| waybar | `~/.config/waybar/{config.jsonc,style.css}` |
| tray-tui | `~/.config/tray-tui/config.toml` |
| zsh | `~/.zshrc` |

这些都是 home-manager 的软链接，**直接改会被下次 switch 覆盖**；
要改就改仓库里的 `dotfiles/`，再 `just switch`。
